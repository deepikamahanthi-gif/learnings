# Java Programs Repository

This repository contains Java programs for:

- Number Programs
- Array Programs
- String Programs

## Topics Covered

### Number Programs
- Reverse Number
- Palindrome Number
- Armstrong Number
- Prime Number
- Factorial
- Fibonacci Series

### Array Programs
- Largest Element
- Smallest Element
- Second Largest
- Reverse Array
- Sorting
- Duplicate Elements

### String Programs
- Reverse String
- Palindrome String
- Count Vowels and Consonants
- Remove Spaces
